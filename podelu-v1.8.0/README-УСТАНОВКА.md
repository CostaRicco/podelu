# По делу · установочная сборка v1.8.0

Полный архив для log.markitan.site. Совместим со схемой v1.7.0.
Все файлы видимые, именованный компонентный шаблон app, ядро Битрикса не заменяется.
Сайт и репозиторий при подготовке архива не изменяются.

## Обновление

1. Сохраните резервную копию базы и файлов v1.7.0.
2. По HTTPS войдите администратором Битрикса.
3. Содержимое upload загрузите в корень сайта с заменой файлов.
   В корне: index.php, clients/, works/, settings/, local/ рядом с существующим bitrix/.
4. Откройте /local/tools/podelu/install.php, проверьте текущий сайт.
5. На выделенном поддомене оставьте галочку podelu и запустите обновление.
6. При корректной v1.7.0 новых полей не требуется. Клиенты, пакеты, задачи, шаблоны и минуты не очищаются.
7. Удалите только install.php. action.php, view.php, options.php и bootstrap.php оставьте.
8. Сбросьте кеш Битрикса, закройте старые формы, выполните жёсткое обновление браузера.
9. Проверьте v1.8.0 в общем хедере и тестовые сценарии ПРОВЕРКА.md.

Требуется актуальный Битрикс, PHP 8.1+, mbstring, highloadblock, MySQL/MariaDB и InnoDB.
Установщик повторно запускаемый, добавляет только недостающее, не меняет типы существующих полей.
При частичной ошибке DDL автоматически не откатывается. Не запускайте одновременно в разных вкладках.

## Настоящее круговое меню

Кнопка добавления фиксирована по центру над навигацией на всех административных страницах.
Из карточки клиента/журнала с выбранным клиентом он передаётся в форму. Иначе клиент выбирается при вводе.
Кнопка открывает внутреннее кольцо типов. Наведение/клик раскрывает внешние сектора времени.
Нажатие 40 мин открывает форму с 0 ч / 40 мин, но ничего не записывает до сохранения.
Центр колеса, фон, повторный клик нижней кнопки и Escape закрывают меню.
На телефоне это то же SVG-кольцо, не сетка прямоугольных кнопок.
На низком ландшафтном экране колесо центрируется, нижние кнопки временно скрываются.

Все активные шаблоны доступны через «Все шаблоны» и стрелки страниц по пять.
Всегда есть сектор «Своя работа», далее произвольное время через «Другое».
Клавиатура: Tab, Enter/Space, влево/вправо по типам, вниз к времени, вверх к типу, Escape.
При переходе между кольцами выбранная категория сохраняется, от пустого зазора меню не закрывается.

## Анимация и CDN

Локальный motion.js асинхронно подключает фиксированную GSAP 3.13.0:
https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js

Ни UI, ни запись данных не ждут загрузку CDN. Если он недоступен, работает локальная
анимация через Element.animate. При отсутствии обоих механизмов кнопки и геометрия остаются рабочими.
referrerPolicy no-referrer задан для внешнего скрипта. Для разрешающей CSP может потребоваться
добавить cdn.jsdelivr.net в script-src; если политика запрещает его, используется fallback.
Включение CDN означает выполнение стороннего кода в браузере, поэтому версия зафиксирована.
Обновления библиотеки не подтягиваются автоматически. Учтён prefers-reduced-motion.

## Удаление выполнений

Раскройте задачу. В каждой дочерней строке рядом с «Править» есть «Удалить».
Подтверждение показывает дату и длительность. После удаления баланс пересчитывается,
минуты возвращаются в пакет. Задача не удаляется.
То же действие оставлено в панели редактирования выполнения.
Пустая повторяющаяся группа может исчезнуть из выбранного месяца, но сохраняется в базе
и будет использована при следующем вызове шаблона того же клиента/направления.
Удаление задачи блокируется, пока есть связанные выполнения. Массового каскадного удаления нет.

Каждое удаление: POST, check_bitrix_sessid, IsAdmin и проверка принадлежности записи клиенту.
Не удаляйте связанные данные вручную в технической админке.

## Высота и заголовки

Рабочая область имеет минимальную высоту доступного окна, а не фиксированную высоту.
Длинные страницы растут и прокручиваются. Учтено положение общего хедера и панели Битрикса.
Внизу есть запас, чтобы фиксированные кнопки не закрывали последние строки/формы.
Внутри страницы небольшой H1: Клиенты / Работы / Настройки, в карточке имя клиента.
Бренд и версия остаются только в общем хедере.

## Сохранённые правила учёта

Календарный месяц, без переноса неиспользованных часов и перерасхода.
Фактическое время целыми часами/минутами, от 1 минуты до 24 часов за запись.
Договорные лимиты в часах с шагом 0,25. 40 минут не округляются до 45.
Общий пакет имеет один баланс направлений. Работа без пакета не уменьшает лимит.
Доступно = сумма положительных остатков, перерасход отдельно и не гасится другим пакетом.
Условия one/from и исключение месяцев сохраняются. Пакет с временем нельзя сделать недействительным.
Работа с первым временем сохраняется одной транзакцией по клиенту в InnoDB.
Повторные запросы с тем же ключом не создают дубль; другой payload с тем же ключом отклоняется.
Полного аудита/защиты от конфликтующего ручного редактирования нет: последнее сохранение выигрывает.

Созвоны по умолчанию группируются по клиенту, шаблону и направлению. Пустая группа в месяце
не показывается. Старые похожие задачи не объединяются автоматически. Завершение группы
приводит к новой группе при следующем шаблонном созвоне. История не удаляется.

## Проверки и ограничения

Реально выполненные проверки перечислены в BUILD-CHECKS.json.
PHP/Битрикс в среде сборки отсутствуют: серверные действия, миграция и SQL там не запускались.
Перед реальными данными пройдите тест на хостинге после резервного копирования.
CLI-проверки чистой логики: php tests/run.php из распакованного архива вне публичной папки.
Папки tests, preview и документацию не нужно загружать на публичный сайт.
preview/index.html является отдельным локальным визуальным стендом, не создаёт записи.
Для MVP справочники/журналы читаются в память, очень большие объёмы требуют оптимизации.
Нет клиентских страниц, вложений, таймера, уведомлений и автоматического deploy.

Если ошибка, пришлите текст/скриншот без sessid, cookie и паролей. Логи AddMessage2Log:
markitan.podelu, markitan.podelu.view, markitan.podelu.options, markitan.podelu.install.
Не включайте публичные SQL-трассировки. Не меняйте права на 777.
Для отката после новых записей восстанавливайте согласованную копию базы и файлов.
