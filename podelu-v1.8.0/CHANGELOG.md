# По делу · v1.8.0

Отличия от v1.7.0:
- Настоящие SVG-сектора внутреннего кольца и внешняя дуга длительностей вместо кнопок веером.
- Одна глобальная кнопка «Добавить работу» над нижней навигацией, убрана из фильтров.
- Полное колесо раскрывается выше кнопки и помещается по ширине/высоте экрана.
- На очень низких экранах колесо центрируется, нижние кнопки временно скрываются;
  закрытие доступно через центр колеса, фон и Escape.
- Типы работ внутри, 15/40/60 минут и «Другое» снаружи. До пяти избранных плюс «Своя работа».
- Все шаблоны доступны постранично на том же круге.
- Устойчивые hit-path, анимируются только визуальные SVG-группы.
- GSAP 3.13.0 подгружается асинхронно с jsDelivr, есть локальный WAAPI fallback.
- Прямое удаление выполнения из дочерней строки с подтверждением и серверной проверкой клиента.
- Удаление задачи по-прежнему не удаляет её выполнения каскадно.
- Минимальная высота бежевой рабочей области по доступной высоте окна, нижний запас под фиксированные кнопки.
- Небольшой H1 внутри каждой страницы, без дублирования бренда и версии.
- Сохранены точные минуты, шаблоны, группировка, AJAX, права и защита пакетов.
- Схема v1.7.0 не меняется. Обновляется отметка версии; недостающие старые сущности создаются при необходимости.

Архив полный, все файлы/папки видимые. Клиентский доступ, таймер, вложения и автоматический deploy не входят.
